# scriptwriter — the curiosity loop

The whole channel lives or dies on whether the first line makes the brain
need to know the answer, and whether the last line pays that off with a twist
instead of a recap. Everything else in the script is load-bearing for that
one arc.

## The 5 beats

Default budget for a 28–32s / 75–85 word script (~2.7 words/sec). Scale every
beat proportionally for other durations — don't just pad the middle.

1. **Myth** (~15–18 words) — state the thing everyone already believes, flatly
   and confidently, like you're about to agree with it.
2. **Twist** (~12–15 words) — the pivot. "But..." / "Except..." / a flat
   contradiction. This is the hook payoff for whatever made someone stop
   scrolling.
3. **Mechanism A** (~18–22 words) — the first concrete piece of *how it
   actually worked/works*. Specific, physical, visual — something a camera
   could show.
4. **Mechanism B** (~18–22 words) — the second piece, building on A. Often
   the part that makes the twist make sense (the "oh, that's why" beat).
5. **Kicker** (~10–14 words) — closes the loop, but by reframing, not
   summarizing. It should recontextualize the twist, not restate it.

Duration scaling: `words ≈ seconds × 2.7`. Keep the beats in roughly the same
proportion (18/14/24/28/13 % of the total) rather than stretching one beat and
leaving the others thin.

## Voice
Confident documentary narrator. Declarative sentences, not questions (the
question is implicit in the myth beat, not spelled out as "have you ever
wondered..."). Occasional direct address ("you've heard this one") is fine in
the myth beat only — everything after should read like someone telling you a
fact, not narrating a mystery.

## The rewrite pass (always run after the first draft)
1. **Cut hedges.** Delete "maybe," "might have," "some say," "possibly,"
   "experts believe," "it's thought that." State the mechanism as fact — the
   angle from Phase 2 already earned you the right to assert it.
2. **Concretize numbers.** "A long time" → an actual figure. "Huge" → an
   actual measurement or comparison. "Ancient" → an actual era or count of
   centuries. Vague magnitude words are cheap; a specific number is what
   makes the visual model (and the viewer) picture something.
3. **Kill adjectives that don't render.** "Fascinating," "incredible,"
   "amazing," "mysterious" describe the viewer's reaction, not anything a
   camera can show. If an adjective doesn't correspond to a visual, cut it —
   the visuals should earn the reaction, not the narration claim it.

### Example
Before: *"For a long time, people believed the ancient wall was destroyed by
a huge and mysterious army. But some historians now think something else
might have happened."*
After: *"For a decade, everyone blamed a 40,000-man army for the wall's
collapse. The dig site says otherwise."*

## Kicker guidance
The kicker is not "and that's the real story" — it's a line that makes the
myth from beat 1 look different in hindsight. If you can delete the kicker
and the script still feels finished, it's too flat; rewrite it so the last
five words are doing new work.
