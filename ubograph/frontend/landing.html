Security and audit

A record of what was checked

What the platform does today, stated plainly.

Password-protected access

A deployed workspace sits behind a login, so your data-source quota is not open to anyone with the URL.

Keys stay on the server

API keys are read from the environment and scrubbed from any error message before it reaches the screen.

Activity log

Every search, report view, saved case and export is recorded with a timestamp.

Review history

A revised adverse-media decision is saved as a new row, so the trail shows what changed and when.

Cases and logs are stored in the instance's local database. Connect persistent storage before relying on it as a system of record.
